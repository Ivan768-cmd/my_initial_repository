# Мои расходы

Telegram-бот для учёта личных расходов и доходов.

Пишешь обычным сообщением:
- `Такси 450`
- `Продукты 1200`
- `Зарплата 85000`

Бот сам распознаёт сумму и категорию.

## Возможности
- быстрый ввод трат текстом
- баланс и история
- лимиты по категориям
- бюджет на месяц
- цели
- напоминания
- простые отчёты за неделю и месяц
- пробный период 3 дня

## Стек
- Python
- aiogram 3
- PostgreSQL
- Redis
- Docker
